# Assignment 4 — Part 1

Extract the ZIP file and open a terminal in the folder containing `p1.py`.

Run:

```bash
python3 -m pip install numpy matplotlib scikit-image
python3 p1.py
```

The first image set (`set1`) appears in two plot windows. Close both windows to automatically display the second image set (`set2`). Matrices and errors are printed in the terminal.

The four output images are also saved automatically in `results`.
