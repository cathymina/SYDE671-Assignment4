# SYDE 671 Assignment 4

This repository contains the code and report for SYDE 671 Assignment 4.

## Files

- `SYDE671_ASS4.pdf`: Complete written report.
- `SYDE671_ASS4_code/`: Python code, input data, and output images for Parts 1–4.

## Requirements

Python 3 is required. Install the packages with:

```bash
python3 -m pip install numpy scipy matplotlib scikit-image
```

## Run the code

Open a terminal in the folder that contains the Python file for the part you want to run.

For Part 1:

```bash
cd SYDE671_ASS4_code/SYDE671_Part1
python3 p1.py
```

For Part 2:

```bash
cd SYDE671_ASS4_code/SYDE671_Part2
python3 p2.py
```

For Part 3:

```bash
cd SYDE671_ASS4_code/SYDE671_Part3
python3 p3.py
```

For Part 4:

```bash
cd SYDE671_ASS4_code/SYDE671_Part4
python3 p4.py
```

Part 4 may take several minutes because it runs the complete structure-from-motion reconstruction.

The generated output images are saved in the `results` folder of each part.
